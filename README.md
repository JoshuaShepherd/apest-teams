## Overview

**APEST Teams** is a diagnostic and discipleship platform designed to evaluate, activate, and mature the collective fivefold ministry (Apostle, Prophet, Evangelist, Shepherd, Teacher — Ephesians 4:1-16) of leadership teams (staff, elder boards, church plant core teams, and network cabinets).

This repository contains:
1. **Complete Authoritative Documentation (`docs/`):**
   - Architectural plans, functional screen specifications, visual design catalogs, and canonical 5Q diagram assets.
   - Comprehensive market strategy, buyer personas, target audience definitions, and the complete 30-slide executive presentation.
   - Full reference case study data: **Restoration Road Community Church** (Denver, CO — 5 team member profiles, vocational reports, and JSON schemas).
   - Historical preview designs, copy briefs, and HTML prototypes.
2. **Autonomous Execution Engine:**
   - [`PROMPT.md`](file:///c:/Users/Josh/Desktop/apest-teams/PROMPT.md): Master React / Next.js implementation specification, component hierarchy, design tokens, mathematical algorithms, and agent prompts.
   - [`RUNNER.md`](file:///c:/Users/Josh/Desktop/apest-teams/RUNNER.md): Autonomous execution runner, closed-loop state machine, automated phase verification gates, and self-healing diagnostic algorithm.
   - [`STATE.md`](file:///c:/Users/Josh/Desktop/apest-teams/STATE.md): Active progress ledger and granular checklist tracking implementation progress to 100%.
